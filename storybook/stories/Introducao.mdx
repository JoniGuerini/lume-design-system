# Lume Design System

Os 58 componentes do Lume, com o CSS e o JavaScript reais do design system. Use a barra de cima para trocar o **tema** (claro e escuro) e o **idioma** (português, inglês e espanhol).

Cada componente tem uma história por seção da página dele no site: exemplo, variantes, tamanhos, estados e o que mais a página mostra. A documentação completa, com acessibilidade, tokens e regras de uso, fica em [lumeui.dev](https://lumeui.dev).

## Instalar

```html
<link rel="stylesheet" href="https://lumeui.dev/v/0.38/lume.css">
<script type="module">
  import { initTheme } from 'https://lumeui.dev/v/0.38/lume.js';
  initTheme();
</script>
```

## React

Na seção **React**, os mesmos componentes em `.tsx` (pasta `react/` do zip de cada versão), com o valor no estado do React. Como instalar e a lista completa: [Usar com React](https://lumeui.dev/#/recursos/react).

Para uma IA construir com o Lume, aponte para [lumeui.dev/llms.txt](https://lumeui.dev/llms.txt).
